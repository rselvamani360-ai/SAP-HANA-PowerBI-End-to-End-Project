# 🚀 SAP HANA to Power BI – End-to-End Sales Analytics Project

## 📖 Project Overview

This project demonstrates an end-to-end enterprise analytics workflow by importing a sales dataset into SAP HANA and connecting it to Microsoft Power BI to create an interactive business dashboard.

The objective was to understand how enterprise data moves from a database to business intelligence dashboards for better decision-making.
