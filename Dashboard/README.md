# Power BI Dashboard

This folder contains the Microsoft Power BI dashboard developed for this project.

## Dashboard Features

- Total Sales KPI
- Average Sales KPI
- Total Customers
- Sales by Region
- Sales by Country
- Material Category Analysis
- Interactive Filters
- Business Insights

## File Included

- SAP_SALES_DATA.pbix

> Note:
> The dashboard is configured to connect to a local SAP HANA database. Update the SAP HANA server details before refreshing the data.
